# Android Shortcut Setup

## Add to Home Screen (PWA)
1. Open Chrome on Android
2. Go to https://your-vercel-domain.vercel.app
3. Tap menu (3 dots) → "Add to Home screen"
4. Name it "CodePhantom"
5. Tap "Add"

## Enable Voice Input
1. Long-press the home screen
2. Tap "Widgets"
3. Find "Google" → "Voice Search"
4. Drag it to your home screen
5. Tap the microphone icon to speak

## Create Quick Shortcut
1. Long-press the CodePhantom app icon
2. Tap "Edit"
3. Long-press the icon
4. Drag to home screen
5. Now one-tap to open
